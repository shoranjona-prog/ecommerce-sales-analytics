# E-Commerce Sales & Customer Behavior Analytics

This project focused on analyzing e-commerce transaction data to discover purchasing patterns, seasonal trends, and customer segments. The goal was to optimize marketing campaigns and improve overall profit margins.

## Key Features
- **Data Cleaning:** Removed duplicate transactions and handled missing values using Python.
- **RFM Analysis:** Segmented customers based on Recency, Frequency, and Monetary values to identify high-value buyers.
- **KPI Tracking:** Monitored Customer Lifetime Value (CLV), Average Order Value (AOV), and monthly revenue growth.

## Tools & Technologies Used
- **Language:** Python
- **Libraries:** Pandas, NumPy
- **Database:** SQL
- **Version Control:** Git & GitHub
